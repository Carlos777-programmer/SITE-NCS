# NCS Garage — Estética & Som Automotivo 🚗⚡

Landing page e painel de apresentação de alta performance para a **NCS Garage**, especializada em estética automotiva, elétrica avançada e som de alta qualidade. O projeto foi desenvolvido com foco em experiência do usuário (UX), design moderno em tema escuro (*dark mode*) e conversão direta via WhatsApp.

---

## 🚀 Principais Funcionalidades

* **Design Imersivo & Moderno:** Interface em tema escuro (`dark`), com efeitos de *spotlight* com o movimento do mouse, cartões com brilho dinâmico (*glow cards*) e texturas sutis.
* **Simulador de Orçamento Dinâmico:** Permite ao cliente selecionar o tipo de veículo, prioridade e serviços desejados para calcular uma prévia comercial e gerar instantaneamente uma mensagem formatada para envio no WhatsApp.
* **Catálogo de Serviços com Filtros:** Filtragem interativa por áreas (Estética, Som, Elétrica) e tipos de serviço (Preventiva, Upgrade, Corretiva).
* **Portfólio de Projetos & Galeria Expandida:** Listagem de trabalhos realizados com suporte a fotos e vídeos, modal de detalhes dinâmico, campo de pesquisa de projetos e filtros por tipo de veículo (Hatch/Sedan, SUV/Picape, Motos, Esportivo/Premium).
* **Integração com API Externa:** Consumo dinâmico de projetos recentes através de uma API dedicada com suporte a modo estático em caso de falhas.
* **Totalmente Responsivo:** Menu mobile integrado, layout fluido e adaptado para qualquer dispositivo (smartphones, tablets e desktops).

---

## 🛠️️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas e leves, focadas em performance e facilidade de manutenção:

* **HTML5 & CSS3** (com variáveis customizadas, animações e gradientes nativos).
* **Tailwind CSS** (via CDN, com configuração personalizada de paleta de cores e temas).
* **Lucide Icons** (para ícones modernos e minimalistas).
* **Google Fonts** (Tipografia com as fontes *Inter* e *Space Grotesk*).
* **JavaScript Moderno (ES6+)** para interatividade, manipulação de DOM e consumo assíncrono de API.

---

## 📂 Estrutura do Projeto

O projeto está centralizado em um único arquivo principal para garantir simplicidade e portabilidade:

* `index.html` — Contém toda a estrutura HTML, estilos CSS customizados, scripts de interatividade e lógica de integração com a API de portfólio.

---

## ⚙️️ Como Executar o Projeto

Como o site utiliza apenas arquivos estáticos, executá-lo é extremamente simples:

1. Baixe ou copie o código fonte para o seu ambiente local.
2. Certifique-se de que o arquivo está nomeado corretamente como `index.html`.
3. Dê um duplo clique no arquivo para abri-lo em qualquer navegador web moderno, ou utilize uma ferramenta de desenvolvimento como o **Live Server** (no VS Code) para visualizar localmente.
